The desktop app is deepLe for macOS, Windows and Linux, with the same interface as the web app and no setup.

It runs the whole app on your computer, including the server that talks to your AI provider. Your notebooks are kept in a file on your disk instead of in a browser.

The installer includes the local service that connects AI subscriptions. Open **Settings → AI → AI subscriptions** and choose an account; the provider handles the sign-in in your browser.

## Download

The [download page](/download) lists published deepLe installers when available. You can also [build the app](#build-from-source) from your checkout.

| System  | File                                                                           |
| ------- | ------------------------------------------------------------------------------ |
| macOS   | `.dmg`: `arm64` for Apple silicon (M1 and later), `x64` for Intel Macs         |
| Windows | `.exe` installer for 64-bit Windows 10 and 11                                  |
| Linux   | `.AppImage`, which runs on most distributions, or `.deb` for Debian and Ubuntu |

## Install

<Steps>
<Step>

### macOS

Open the `.dmg` and drag **deepLe** onto **Applications**. Then open it from Applications or Launchpad.

</Step>
<Step>

### Windows

Run the installer. It installs deepLe for your user account and opens it.

</Step>
<Step>

### Linux

Make the AppImage executable and run it:

```bash
chmod +x better-vault-*.AppImage
./better-vault-*.AppImage
```

On Debian or Ubuntu you can install the `.deb` with `sudo apt install ./deepLe-*.deb` instead.

</Step>
</Steps>

## Updates

The desktop app doesn't update itself. To move to a new version, install or build the new version over the old one; your notebooks stay in the data folder below.

## Where your data lives

Notebooks, sources, chats, Studio outputs and settings are kept in one SQLite file, `better-vault.sqlite`, in the app's data folder.

| System  | Data folder                                  |
| ------- | -------------------------------------------- |
| macOS   | `~/Library/Application Support/better-vault` |
| Windows | `%APPDATA%\better-vault`                     |
| Linux   | `~/.config/better-vault`                     |

Uninstalling the app leaves this folder in place, so your notebooks are still there if you install it again.

## Move notebooks from the browser

The web app and the desktop app keep separate data. To bring your browser notebooks over, open **Settings → Storage and data** in the web app and export a backup. Then open the same screen in the desktop app and import it. Backups never contain API keys, so paste your keys again in **Settings → AI → AI providers**.

## Local models

The desktop app works well with Ollama and LM Studio. Start the model server, turn the provider on in **Settings → AI → AI providers**, and your sources never leave your computer. [Providers and models](/docs/providers) has the steps.

## Build from source

You can also build the app from a checkout of the repository. From the project root, run `bun run setup`, then `bun run desktop:pack` to build an unpacked app or `bun run desktop:dist` to build an installer. The build downloads the subscription proxy and checks its checksum before bundling it.
